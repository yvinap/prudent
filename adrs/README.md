# Architecture Decision Records

This folder captures the significant architectural decisions for Prudent. Each ADR is immutable once accepted; superseding decisions are recorded as new ADRs that reference the older one.

Format follows [Michael Nygard's template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
